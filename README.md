# Alex Morgan — Creative Web Developer

A fictional personal portfolio website for a freelance web-development portfolio, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Features

- Deep-navy, electric-blue, and cyan technology-inspired visual design
- Responsive hero, about, skills, featured projects, services, process, contact form, and social links
- CSS/HTML-built code editor and project illustrations; no external image dependencies
- Responsive navigation, smooth in-page links, scroll reveal effects, and reduced-motion support
- Demo contact form with browser validation and visible confirmation; project and service links preselect a relevant inquiry type

## Fictional demo content

Alex Morgan, the project concepts, contact details, and social profiles are fictional placeholders. The contact form does not send or store messages. Replace all demo details and connect a form service before using the site for a real person or business.
